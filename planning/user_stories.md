# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

1. **Lender:** A neighborhood resident who registers to list their personal tools or skills to share or rent out to the community.
2. **Borrower:** A neighborhood resident looking to rent, borrow, or request specific tools or skills from nearby listings.
3. **Guest:** An unauthenticated visitor who wants to browse the platform's local catalog before deciding to join.

## Draft User Stories

1. As a Guest, I want to browse available items on the home feed, so that I can see if anyone in my area is lending a tall ladder before I create an account.
2. As a Guest, I want to filter listings by category (e.g., Gardening), so that I don't have to scroll through unrelated listings to find what I need.
3. As a Lender, I want to create a new tool or skill listing with a title, description, and category, so that my neighbors know exactly what I am offering.
4. As a Lender, I want to edit my tool listing's description, so that I can update its condition or modify specific pickup instructions.
5. As a Lender, I want to delete a listing, so that I can permanently remove it if I no longer own the tool or am no longer available to teach the skill.
6. As a Borrower, I want to view a specific item's details page, so that I can read the full description and check its availability schedule.
7. As a Borrower, I want to select a start and end date to reserve a tool directly from its detail page, so that the reservation process is quick and seamless.
8. As a Borrower, I want to receive a clear error message if I accidentally try to reserve a tool for a date in the past, so that I can correct my submission parameters.
9. As a Borrower, I want the system to block me from booking a tool if someone else has already reserved it for those exact dates, so that scheduling conflicts are entirely avoided.
10. As a Lender, I want to view a dashboard summary list of all upcoming reservations made on my tools, so that I can keep track of who is borrowing my equipment and when they will return it.
